# playwright-test-integration-and-dashboard-execution: Playwright Test Integration UI/UX Design

## Overview
This document describes the frontend changes to support browsing and executing static Playwright tests.

## 1. Execution Mode Toggle
The `ExecutionPanel` will feature a segmented control or toggle to switch between **AI Agent** (autonomous) and **Playwright** (static) modes.

### Behavior:
- **AI Agent (Default)**: Shows the standard Jira ticket input and "Execute" button.
- **Playwright**: Hides the Jira input and shows the **Playwright Library** selector.

## 2. Playwright Library Component (`PlaywrightLibrary.tsx`)
A new component that allows users to select a test from the registry.

### Visual Elements:
- **Search Bar**: Filter tests by name or description.
- **Test List**: A scrollable list of available tests with:
  - Name & Description
  - Tags (e.g., "Smoke", "Regression")
  - "Select" button.
- **Selected State**: Displays the currently selected test in the `ExecutionPanel`.

## 3. Terminal Log Viewer
When a static test is running, the `ExecutionLog` component will switch to a **Terminal View**.

### Visual Elements:
- **Monospace Font**: Use a terminal-like font (e.g., Fira Code, Courier).
- **Auto-scroll**: Automatically scroll to the bottom as new lines arrive.
- **ANSI Support**: Basic support for color codes generated by Playwright (if possible).
- **Stream Indicators**: Color-coded indicators for stdout (white) vs stderr (red).

## 4. VNC Stream Persistence
The VNC stream (noVNC iframe) remains the central visual element.
- Since the `PlaywrightExecutor` runs the test on `DISPLAY=:1`, the user will see the browser perform actions in real-time, just like with the AI agent.
- No changes required to the `VNCStream` component, as it simply points to the VNC URL.

## 5. Layout Transitions
- Upon clicking "Run" in Playwright mode, the `ExecutionPanel` collapses (following the progressive disclosure paradigm from TASK-055).
- The `TerminalLog` and `VNCStream` expand to fill the workspace.

## 6. Feedback & Errors
- If a Playwright test fails, the terminal will show the failure details.
- A "Run Failed" banner appears at the top (matching the standard failure UI).
- The user can click "Rerun" to execute the same test again.
