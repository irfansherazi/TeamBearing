### FEAT-050: UI/UX Overhaul & Progressive Disclosure
- **Version**: next
- **Status**: planned
- **Priority**: medium
- **Complexity**: Level 3
- **Description**: Redesign the vQA dashboard to use progressive disclosure, focusing the UI on the current task. Key requirements: (1) Hide previous reports, execution logs, and AC steps by default; (2) Show execution logs and AC steps only after a test starts; (3) Hide the configuration panel (ExecutionPanel) once a test is running to maximize space for the execution output; (4) Implement a modern, intuitive layout that transitions smoothly between "Configuration" and "Execution" modes.
