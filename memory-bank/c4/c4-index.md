## System Overview

vQA is an autonomous AI-driven web QA agent that fetches Acceptance Criteria from Jira tickets, executes them visually against a live browser, and delivers self-contained audit reports.

### Key Containers

1. **vQA Backend**: Python/FastAPI service hosting the AI execution engine (LangGraph), Browser automation (Playwright), and Knowledge Base (RAG).
2. **React Frontend**: TypeScript/React SPA for monitoring runs, reviewing reports, and Human-in-the-Loop interventions.
3. **Redis**: Distributed state and caching (optional for horizontal scaling).

### Primary Data Flows

- **Input**: Jira Ticket (Acceptance Criteria) -> API -> Execution Engine.
- **Execution**: Engine -> LLM -> Planner -> Browser Automation -> Live App.
- **Feedback**: Browser -> Vision/DOM Analysis -> Verifier -> Engine.
- **Output**: Audit Report (screenshots, logs) -> S3/Local Storage.
